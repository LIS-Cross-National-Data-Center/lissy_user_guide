FAQs

How to Contact User Support

For any specific issue not addressed on this page, please contact usersupport@lisdatacenter.org.

When the issue is related to LISSY, please provide the following information wherever possible:

  1. The type of access used (web-based Job Submission Interface vs. email)
  2. The network and operating system from which you attempted to access LISSY (e.g. Princeton University on Windows 7 64-bit)
  3. A description of the exact stage at which the issue occurs (screenshots are welcome)
  4. The error message received, if any
  5. The date and time when the problem occurred
  6. If the problem is related to a specific job, the job number

May I use external files within LISSY?

Yes, but only after review. Send your request, with the file attached, to User Support. If the file meets security standards, you will receive an email with instructions on how to access it.

Can I add an R package or a Stata .ado file?

Not directly. R packages and Stata ado files can only be installed by LIS staff. Please contact User Support to request an installation.

Can I access a previous version of a dataset for replication purposes?

Yes, in some cases. LIS keeps an archive of earlier dataset versions, but it applies only to datasets revised after May/June 2019 and is intended exclusively for peer review or for replicating published results. Access is granted for a maximum of two weeks.

To request it, write to User Support and specify:

  • The database (LIS or LWS)
  • The statistical package used (Stata, R, SAS, or SPSS)
  • The date on which you accessed the dataset(s) and ran your analysis

You will receive an email with instructions on how to access the pre-revised datasets.

For datasets following the 2011 Template (the last version on LISSY before May 2019 for LIS and mid-June 2019 for LWS), select the project LISPRE for the LIS database or LWSPRE for the LWS database.

Are there other ways to access LIS microdata?

LISSY is the standard route, and the microdata cannot be downloaded. Two alternatives exist for researchers who meet the eligibility conditions:

  • SafePod Network (UK). Eligible UK-based researchers can access LIS data from secure SafePods hosted at participating universities. Approval is based on a short project description. See LIS joins the UK SafePod Network.
  • Visiting programmes (Luxembourg). Visitors are hosted on site and work with the microdata on a secure computer without internet access. See the Visiting Scholars Program, and the calls for the LIS(2)ER research stays run jointly with LISER.

Forbidden Words

LISSY automatically applies pre- and post-processing checks to make sure data confidentiality is never breached. Some commands trigger security alerts, for example syntax that displays frequencies on continuous variables or that would print individual records. Do not include the following commands in your job:

Package Forbidden commands
SAS print, NOXWAIT, NOXSYNC
SPSS print
Stata list, erase, rm, pwd, cd, rmdir, type, dir, ls

Messages You May Receive

Message What it means What to do
set for review LISSY detected a potentially suspicious job and moved it to a security area for manual review. Remove any syntax that could print variables, in any language. Reviewed jobs take time, so do not resubmit the same job until it has been handled.
handling listing or job has been automatically killed The output was too long, which is the most common cause. Split your code into several shorter jobs, combine fewer datasets per run, and shorten outputs (SAS: OPTIONS nosource nonotes; Stata: nolog, quietly or noisily).
Could not connect to the server LISSY is temporarily down. Try again later. If the problem persists, contact User Support.
