Import Data

More than a thousand LIS, LWS and LCS datasets are available for use and analysis within LISSY. Learning how to import these datasets is one of the first key steps in the user workflow, as it requires becoming familiar with the built-in tools specifically designed for this purpose.

Before getting started, there are a few important concepts to keep in mind:

  • LIS/LWS/LCS datasets cannot be accessed simultaneously (remember to select the appropriate Project from the dropdown menu in the user interface).

  • Datasets are organized by country and year, following the ccyy naming convention (e.g., de18, de19).

  • In addition, each ccyy dataset is divided by level:

    • household-level file
    • individual-level file

R users have two different methods available to import data into LISSY:

  1. The newer lissyrtools::lissyuse() function

  2. The read.LIS() method, which is still used in some cases, particularly for less frequently used files such as LWS replicate weights

For the remainder of this guide, we will focus on Method 1, which imports the selected LIS datasets into a list, where each element corresponds to a specific country–year dataset.


Method 1: lissyuse()

Using the lissyuse() function from our in-house lissyrtools package has two main advantages:

  1. Imports all datasets available, given specific ISO-2 country codes by default;

  2. Automatically selects the correct data level based on the variables requested;

library(lissyrtools)


Advantage 1: Import entire country series

At the time we are writting this guide, LIS contains 26 datasets on Italy. This means that if the user wanted to import all years it would have needed to manually specify 26 distinct datasets. On top of it, it still had to know and confirm the exact specific years that we have data for each one of the countries.

* it22 it20 it16 it14 it12 ...

To bypass this problem, lissyuse() allows users to import LIS data by specifying the countries they wish to work with via their ISO-2 country codes, as well as optionally filtering by a desired year range.

lis_data <- lissyrtools::lissyuse(
  data = c('it'), 
  vars = "dhi"
)
The list contains the following `household-level` data frames: it22h, it20h, it16h, it14h, it12h, it10h, it08h, it06h, it04h, it02h, it00h, it98h, it95h, it93h, it91h, it89h, it87h, it86h, it84h, it83h, it82h, it81h, it80h, it79h, it78h, it77h.

Important

The output of lissyrtools::lissyuse() will always be a list of data frames. Each ccyy is a different data frame.

To filter the datasets to a shorter time span, the user can also specify the from and to arguments.

lis_data <- lissyrtools::lissyuse(
  data = c("mx", "us"), 
  vars = "dhi",
  from = 2014,
  to = 2016
)
The list contains the following `household-level` data frames: mx16h, mx14h, us16h, us15h, us14h.

Specific datasets can also be selected by specifying its ccyy code

lis_data <- lissyrtools::lissyuse(
  data = c("it16", "mx", "us"), 
  vars = "dhi",
  from = 2014,
  to = 2016
)
The list contains the following `household-level` data frames: it16h, mx16h, mx14h, us16h, us15h, us14h.


Advantage 2: Automatic Data-Level Selection

The second benefit of using lissyuse() is that it automatically imports datasets at the level determined by the variables selected. If the users selects only household-level varaibles in the vars argument such as: disposable household income (dhi), geographic region (region_c) or capital income (hicapital), the data will be loadad at the household level. As soon as the user includes an individual-level variable, such as gender (sex) or labour force status (lfs), the dataset level adjusts accordingly.

To help users identify the imported data level, a message is printed each time lissyuse() is executed. In addition, the names of the datasets include an h suffix when household-level data is loaded.

h_level_data <- lissyrtools::lissyuse(
  data = "lu18", 
  vars = c("dhi", "region_c", "typehh") # only h-level 
)
The list contains the following `household-level` data frames: lu18h.

In the example below, only individual-level variables are specified. In such cases, in addition to the printed message indicating the data level, the names of the data frames will contain a p suffix.

p_level_data <- lissyrtools::lissyuse(
  data = "lu18", 
  vars = c("age", "sex", "relation", "emp", "pi11")
)
The list contains the following `person-level` data frames: lu18p.

If both household-level and individual-level variables are specified in vars, no suffix is added to the name of the data frame.

merged_hhd_ind_data <- lissyrtools::lissyuse(
  data = "lu18", 
  vars = c("dhi", "region_c", "typehh", "age", "sex", "relation", "emp", "pi11")
)
The list contains the following `person-level` data frames: lu18.
names(merged_hhd_ind_data[[1]])

Important

Recap: As soon as an indiviudal-level variable is selected in the argument vars, the data will be loaded at individual-level as well. If only household-level variables are selected, then data will be loaded at household-level. If none are selected, then all variables are considered and consequently data will be at the individual-level.

Tip

Note as well that some variables were imported by default. Variables such as IDs, weights, and others do not need to be defined explicitly, as they are automatically included.


Importing LWS and LCS data

To import data from these databases, one would need to change the selection in the Project drop-down menu, and set the database argument equal to lws or lcs accordingly.

us_lws_data = lissyrtools::lissyuse(
  data = c("us"), 
  vars = c("dnw"), # disposable net wealth - LWS specific variable. 
  from = 2015, 
  database = 'lws' 
)
The list contains the following `household-level` data frames: us22h, us19h, us16h.
names(us_lws_data[[1]])
 [1] "hid"      "inum"     "dnw"      "dname"    "iso2"     "year"    
 [7] "currency" "nhhmem"   "hwgt"     "hpopwgt"  "hwgta"   
be_lcs_data = lissyrtools::lissyuse(
  data = c("be"), 
  vars = c("hc01_t"), # LCS specific variable. 
  from = 2018, 
  database = 'lcs' 
)
The list contains the following `household-level` data frames: be24h, be22h, be20h, be18h.
names(be_lcs_data[[1]])
 [1] "hid"      "hc01_t"   "dname"    "iso2"     "year"     "currency"
 [7] "nhhmem"   "hwgt"     "hpopwgt"  "hwgta"
